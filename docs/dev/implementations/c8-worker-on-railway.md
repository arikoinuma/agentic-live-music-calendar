## Context

C8 puts the pipeline that has run only on a laptop onto Railway, against the hosted databases and DeepInfra, and gives Ari a way to start it on demand in every environment. It is mostly **a container, a handful of dashboard settings and the guards that make those safe**. The pipeline itself does not change. **The scheduled-run gate is not built here: C3.1 built it** (`C3.1-D1`, merged to `main` on November 9, 2026), and C8 relies on it (D4, D6).
